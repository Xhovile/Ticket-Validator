# Ticket Validator

**Ticket Validator is the gate-control tool for BuyMesho and Yava events.**

It is built for event staff to quickly and reliably validate attendee tickets at the entrance — turning a purchased ticket into a controlled, trackable entry.

## What it does

- **Scan tickets** using attendee QR codes.
- **Validate entry** and prevent invalid or duplicate tickets from being admitted.
- **Manage attendees** and review ticket status.
- **Operate by gate/session**, with staff and event context.
- **Support offline workflows** when connectivity is unreliable.
- **Provide manual ticket lookup** when scanning is not practical.

## Who it is for

Ticket Validator is a **staff-facing operational tool**, not the customer ticketing interface. It works alongside the BuyMesho/Yava ticketing ecosystem to handle what happens **at the gate**.

> **BuyMesho/Yava sells and manages tickets. Ticket Validator verifies them at the door.**

## Tech

React · TypeScript · Vite · Tailwind CSS · `html5-qrcode`
